Apresentação: Botequim na Mão

Guia de Migração e Comparativo: Foundation 6 vs Bootstrap 5

Objetivo deste Documento

Este arquivo reúne as principais escolhas arquiteturais do projeto Botequim na Mão, evidenciando como substituímos os padrões do Bootstrap pelos padrões nativos do Foundation Sites 6. Ideal para ser utilizado como apoio visual e técnico durante a apresentação.

1. Sistema de Grid (XY Grid)

O Foundation utiliza o XY Grid (baseado em Flexbox). As colunas são chamadas de cell e o container principal de grid-container e grid-x.

Bootstrap: .container > .row > .col-12 .col-md-6
Foundation: .grid-container > .grid-x .grid-margin-x > .cell .small-12 .medium-6
.cell .small-12 .medium-6
.cell .small-12 .medium-6
<div class="grid-x grid-margin-x">
  <div class="cell small-12 medium-6">Metade no Desktop, Total no Mobile</div>
  <div class="cell small-12 medium-6">Metade no Desktop, Total no Mobile</div>
</div>

2. Botões e Variações

No Foundation, a classe base é .button (em vez de .btn).

Bootstrap: .btn .btn-primary | .btn-outline-primary | .btn-link
Foundation: .button .primary | .button .hollow .primary | .button .clear 
<button class="button primary">Primário</button>
<button class="button hollow primary">Hollow (Outline)</button>
<button class="button clear secondary">Clear (Texto/Link)</button>

3. Cards vs Callouts

O Foundation possui .card (similar ao Bootstrap), mas utilizamos extensivamente os .callout para painéis e alertas.

Bootstrap: .alert .alert-warning ou .card .card-body
Foundation: .callout .warning ou .card .card-section
Callout Warning

Excelente para destacar informações ou formulários (Usado no Carrinho vazio).

Card Section

Ideal para listagem de produtos (Usado no Cardápio).

<!-- Callout (Alerta/Painel) -->
<div class="callout warning">Conteúdo em destaque</div>

<!-- Card Tradicional -->
<div class="card">
  <div class="card-section">Conteúdo do Produto</div>
</div>

4. Classes Utilitárias (Flexbox e Texto)

O Foundation 6 tem um conjunto reduzido de utilitários de margem. Nós trouxemos algumas classes globais (mb-4, fw-bold, rounded-4) no nosso app.css para agilizar o design sem poluir o HTML.

Bootstrap: .d-flex .align-items-center .justify-content-between
Foundation: .flex-container .align-middle .align-justify
Esquerda (align-justify)
Direita
<!-- Container Flexbox Alinhado ao Meio e Espaçado -->
<div class="flex-container align-justify align-middle">
  <div>Item 1</div>
  <div>Item 2</div>
</div>

<!-- Utilitários CSS Próprios (app.css) -->
<div class="fw-bold text-primary mb-4 rounded-circle"></div>

5. Inversão de Tema (Modo Escuro)

Construímos uma arquitetura de Modo Escuro global injetada via JavaScript e CSS Overrides. Quando ativado, adicionamos a classe .dark-theme na tag <body>.

Abaixo, um resumo do CSS contido em app.css:

/* ==================================
   MÁGICA DO MODO ESCURO (app.css)
===================================== */
body.dark-theme {
  /* Inversão do fundo e texto base */
  background-color: #121212 !important;
  color: #f8f9fa !important;
}

/* Redefinição de Painéis e Callouts para um cinza suave */
body.dark-theme .callout,
body.dark-theme .card,
body.dark-theme .top-bar {
  background-color: #1e1e1e !important;
  border-color: #333 !important;
  color: #f8f9fa !important;
}

/* Garantir que inputs não fiquem cegantes */
body.dark-theme input, 
body.dark-theme textarea {
  background-color: #2a2a2a !important;
  color: #fff !important;
  border-color: #444 !important;
}

Essa reestruturação evitou a necessidade de trocar classes via JS elemento por elemento, garantindo alta escalabilidade!
